# ClaimSem v0.2.0

This release adds the encoder-generalization experiments and
reproducibility summaries for ClaimSem root-and-depth-aware pooling.

## Included

- MiniLM-L6-v2 results
- MPNet-base-v2 results
- BERT-base-uncased results
- PatentSBERTa-V2 reported summaries
- Granularity-specific LaTeX artifacts
- Reproducibility metadata
- Non-PatentSBERTa validation summary

Large feature arrays, PCA objects, and prediction files are stored in
the associated private Hugging Face dataset repository.
